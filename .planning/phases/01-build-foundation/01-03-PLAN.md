**If xcodebuild fails:**
- Check `/tmp/xcodebuild_manzo.log` for the error
- Common fixes:
  - "No such file or directory: libmanzo_core.a" → run `cargo build --release --target aarch64-apple-darwin` in `manzo-core/` and verify LIBRARY_SEARCH_PATHS in project.pbxproj
  - "manzo_core.h not found" → verify HEADER_SEARCH_PATHS in project.pbxproj points to `manzo-core/`
  - "Undefined symbols: _manzo_play" → linker is not finding libmanzo_core.a; verify `OTHER_LDFLAGS = -lmanzo_core`
  - "error: unknown target 'aarch64-apple-darwin'" → run `rustup target add aarch64-apple-darwin`
