# Phase 8 — UI Design Contract: Playlist & Library

> Visual and interaction contract for the ManzoPlaylistPanel and PL toggle button.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> This is a native macOS AppKit UI — no web framework, no shadcn, no CSS.
> All measurements are in points (pt), all colors are P3 CGColor values.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | AppKit native (no design system framework) |
| Preset | not applicable |
| Component library | NSPanel, NSTableView, NSButton, NSTextField — AppKit native |
| Icon library | SF Symbols (system-provided, no third-party icon bundle) |
| Font | System font — `.systemFont(ofSize:)` and `.boldSystemFont(ofSize:)` |

**No shadcn initialization gate applies.** This is a pure AppKit/Swift codebase.
Registry safety section is not applicable.

## Spacing Scale

All values in points (pt). Multiples of 4 throughout, matching the Winamp grid.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 pt | Icon gaps, inline row padding, rim inset (0.5 pt sub-grid, see exception) |
| sm | 8 pt | Toolbar button horizontal padding, row left/right inset |
| md | 16 pt | Section padding inside panel body |
| lg | 24 pt | Not used in Phase 8 (panel too narrow) |
| xl | 32 pt | Not used in Phase 8 |

**Exceptions:**
- Rim highlight layer: 0.5 pt inset via `bounds.insetBy(dx: 0.5, dy: 0.5)` — this is a NeoAero specular sub-grid value, not a layout token.
- NSTableView row height: 18 pt — Winamp canonical playlist row height (from `draw_pe.cpp` reference). Does not align to 8-pt scale; this is intentional Winamp parity.
- Toolbar strip height: 16 pt — matches `titleView` / `statusView` height on the main window (kTitleBarHeight = 14 pt; 16 pt gives the toolbar slightly more breathing room for tap targets).
- PL button in main window chrome: 20×12 pt — small label button placed in `statusView`, matching the Winamp mini-button aesthetic.
- Touch target minimum: 44×44 pt is NOT enforced here. This is a desktop-only app on macOS Sequoia 15+; Winamp-canonical small controls are correct.

## Typography

All text rendered with `NSAttributedString` attributes on `NSTextField` subviews or
direct attributed string drawing in a custom `NSTableCellView`.

| Role | Size | Weight | Line Height | Color | Usage |
|------|------|--------|-------------|-------|-------|
| Row body | 11 pt | Regular (400) | 1.36 (≈ 15 pt) | P3(0.78, 0.80, 0.85, 1.0) | Track rows: "{n}. {Artist} – {Title}  [{MM:SS}]" |
| Row body active | 11 pt | Bold (700) | 1.36 | P3(1.00, 1.00, 1.00, 1.0) | Currently playing row — same size, bold weight + ▶ prefix |
| Toolbar label | 11 pt | Regular (400) | 1.0 | P3(0.58, 0.60, 0.65, 1.0) | Track count display ("12 tracks"), toolbar button labels — secondary/dim color distinguishes from row body |
| Missing-file row | 11 pt | Regular (400) | 1.36 | P3(0.50, 0.52, 0.55, 0.70) | Strikethrough attribute applied; same size as row body |

**Constraints:**
- Font: `NSFont.monospacedDigitSystemFont(ofSize: 11, weight: .regular)` for the duration
  field `[MM:SS]` so digit widths are fixed and columns stay aligned across rows.
- Row number prefix and track title use `NSFont.systemFont(ofSize: 11)` /
  `NSFont.boldSystemFont(ofSize: 11)` (non-monospaced).
- Toolbar labels use `NSFont.systemFont(ofSize: 11, weight: .regular)` with color
  P3(0.58, 0.60, 0.65, 1.0) — dim secondary color differentiates toolbar labels from row body
  without requiring a separate font size.
- No heading or display roles are needed in this panel.

## Color

All brand colors are `CGColor(colorSpace: .displayP3)` — never sRGB, never `NSColor(calibratedRed:)`.
Source of truth: `NeoAeroLayerFactory.palette(for:)` in `NeoAeroLayer.swift`.

### Panel Chrome Colors (reused from existing NeoAeroLayerFactory)

The playlist panel applies the same NeoAeroLayerFactory chrome as the main window.
The active `ManzoVisualStyle.colorTheme` drives the palette. Default theme is `.winampClassic`.

| Role | P3 Components | Usage |
|------|--------------|-------|
| Base top (winampClassic) | P3(0.09, 0.09, 0.16, 1.0) | Panel chrome base gradient top — #181829 equivalent |
| Base bottom (winampClassic) | P3(0.22, 0.22, 0.35, 1.0) | Panel chrome base gradient bottom — #39395A equivalent |
| Specular top | P3(1.0, 1.0, 1.0, 0.50) | White-alpha specular band (top of chrome) |
| Specular mid | P3(1.0, 1.0, 1.0, 0.08) | Specular band fade |
| Lower glow | P3(1.0, 1.0, 1.0, 0.12) | Bottom edge glow |
| Rim highlight | P3(1.0, 1.0, 1.0, 0.45) | 1 pt border inset |

### NSTableView Content Area Colors

The NSTableView background is transparent (`.clear`) so the NeoAero base gradient shows
through. Text colors follow the dark-on-dark Winamp aesthetic.

| Role | P3 Components | Usage |
|------|--------------|-------|
| Row text — normal | P3(0.78, 0.80, 0.85, 1.0) | Default track row text |
| Row text — active | P3(1.00, 1.00, 1.00, 1.0) | Currently playing track (bold + ▶) |
| Row text — missing | P3(0.50, 0.52, 0.55, 0.70) | Missing-file row (strikethrough + dimmed) |
| Row selection bg | P3(0.20, 0.40, 0.65, 0.40) | NSTableView selection highlight (semi-transparent blue) |
| Row separator | P3(1.0, 1.0, 1.0, 0.06) | Subtle 1 pt horizontal divider between rows |
| Toolbar strip bg | Same as base gradient | Re-applies simplified NeoAero via `makeSimplified()` |
| Toolbar button text | P3(0.58, 0.60, 0.65, 1.0) | "[+]", "[−]" button labels and track count label — secondary/dim color |

**60/30/10 mapping for this panel:**
- 60% dominant surface: panel chrome (base gradient P3 navy/indigo) — fills the entire panel background
- 30% secondary: NSTableView content area (transparent — shows chrome through) with row separators
- 10% accent: active-track white text + ▶ symbol + selection highlight blue — accent is reserved ONLY for the currently playing row and active selection

**Destructive color:**
- No dedicated destructive red is introduced in Phase 8. The [−] Remove button is standard toolbar styling. Actual removal does not require a destructive color confirmation because the playlist is persisted (user can re-add). Track removal is not permanent destruction of a file.

## Panel Layout: ManzoPlaylistPanel

### Window Geometry

| Property | Value | Source |
|----------|-------|--------|
| Width | 275 pt fixed | Winamp `config_pe_width = 275` (CONTEXT.md D-01) |
| Initial height | 116 pt | Winamp `config_pe_height = 116` (CONTEXT.md D-01) |
| Minimum height | 60 pt | Enough for toolbar + 2 rows; prevents unusably small panel |
| Maximum height | Unconstrained | User stretches taller to see more tracks |
| Width resizable | No — locked | Winamp canonical: width never changes |
| Height resizable | Yes | NSPanel resize mask: vertical only |
| Corner radius | 10 pt | Matches main window `cornerRadius = 10` |

### Panel Internal Layout (top-to-bottom)

```
┌─────────────────────────────────────┐  ← cornerRadius = 10
│  titleView  (16 pt)                 │  ← "PLAYLIST EDITOR" label, drag region
│  NeoAero simplified chrome (base+rim)│
├─────────────────────────────────────┤
│  bodyView  (fills remaining height) │  ← NSTableView fills 100% of bodyView
│  NSTableView:                       │
│    18. Artist – Title       [3:45]  │  ← row body text, 11 pt, 18 pt row height
│  ▶ 19. Artist – Title       [4:12]  │  ← active row: bold, white, ▶ prefix
│    20. Missing File.mp3     [2:30]  │  ← missing: strikethrough, dimmed
│    ...                              │
│                                     │
│  NeoAero full chrome (base→rim)     │
├─────────────────────────────────────┤
│  toolbarView (16 pt)                │  ← [+] Add  [−] Remove  │  12 tracks
│  NeoAero simplified chrome (base+rim)│
└─────────────────────────────────────┘
```

### titleView (16 pt)

- Height: 16 pt (NSLayoutAnchor `heightAnchor.constraint(equalToConstant: 16)`)
- Contains: `NSTextField` label "PLAYLIST EDITOR" in 11 pt regular, all-caps, aligned center
- Text color: P3(0.58, 0.60, 0.65, 1.0) — dim secondary color, Winamp-style panel label
- Also serves as the drag region: `mouseDown` falls through to `NSPanel.performDrag(with:)` if not on a control
- NeoAero layer: `NeoAeroLayerFactory.makeSimplified(style:bounds:)` — base + rim, no specular

### bodyView (fills remaining height)

- Fills all space between titleView and toolbarView
- Contains: `NSScrollView` wrapping `NSTableView`, pinned to all 4 edges with 0 pt margin
- `NSScrollView.drawsBackground = false`, `backgroundColor = .clear`
- `NSTableView.backgroundColor = .clear`, `NSTableView.selectionHighlightStyle = .none` (custom selection drawing via `NSTableRowView`)
- NeoAero layer: `NeoAeroLayerFactory.make(style:bounds:)` — full 5-layer chrome, inserted at `bodyView.layer` index 0

### toolbarView (16 pt)

- Height: 16 pt (NSLayoutAnchor `heightAnchor.constraint(equalToConstant: 16)`)
- Contains three elements arranged horizontally:
  1. `[+]` Add button — leading, 8 pt left inset, 24×16 pt, triggers NSOpenPanel
  2. `[−]` Remove button — 4 pt gap after `[+]`, 24×16 pt, removes selected row
  3. Track count label — trailing, 8 pt right inset, right-aligned, "N tracks"
- Button style: `NSButton.bezelStyle = .inline`, `isBordered = false`, custom attributed title
- NeoAero layer: `NeoAeroLayerFactory.makeSimplified(style:bounds:)` — base + rim, no specular

## NSTableView Row Rendering

### Row Format

```
{8pt} {rowNum}. {Artist} – {Title}  {tabstop}  [{MM:SS}] {8pt}
```

- Left inset: 8 pt
- Right inset: 8 pt
- Duration `[MM:SS]` is right-aligned in its own `NSTextField` within the row
- Row number and track string share the remaining width

### Active Row (currently playing)

```
{8pt} ▶ {rowNum}. {Artist} – {Title}  {tabstop}  [{MM:SS}] {8pt}
```

- ▶ rendered as SF Symbol `"play.fill"` at 9 pt, or literal "▶" as Unicode character U+25B6
- Font: `NSFont.boldSystemFont(ofSize: 11)` for row number, artist, title
- Duration font remains monospaced: `NSFont.monospacedDigitSystemFont(ofSize: 11, weight: .bold)`
- Text color: P3(1.0, 1.0, 1.0, 1.0) — pure white
- No row background tint (CONTEXT.md D-08 — consistent with dark CALayer aesthetic)

### Missing-File Row

- Same format as normal row, no ▶ prefix
- `NSStrikethroughStyleAttributeName` applied to the full track string
- Text color: P3(0.50, 0.52, 0.55, 0.70) — dimmed grey-blue
- Row remains selectable and removable

### Row Selection

- `NSTableRowView` subclass draws a custom selection background: P3(0.20, 0.40, 0.65, 0.40)
- Selection is a rounded rect with `cornerRadius = 3 pt`, inset 2 pt from row edges
- `NSTableView.selectionHighlightStyle = .none` — disables system default selection drawing

### Row Separator

- 1 pt `CALayer` divider at the bottom of each row
- Color: P3(1.0, 1.0, 1.0, 0.06) — barely visible white line, consistent with NeoAero layering
- `NSTableView.gridStyleMask = []` — disable system grid; draw separator via `NSTableRowView.drawSeparator`

### Drag-Reorder Visual

- During drag: the dragged row shows a system drag proxy (NSTableView default drag image behavior)
- Drop indicator: a 2 pt horizontal line between rows, color P3(0.20, 0.40, 0.65, 0.80) — same blue as selection, fully opaque
- No row animation on drop; table reloads the affected rows via `moveRow(at:to:)`

## PL Toggle Button (Main Window Chrome)

- Location: `statusView` in `ManzoRootView`, trailing side, 8 pt right inset
- Size: 20×12 pt
- Label: "PL" in 9 pt bold, P3(0.78, 0.80, 0.85, 1.0)
- Active state (panel visible): label color P3(1.0, 1.0, 1.0, 1.0), background P3(0.20, 0.40, 0.65, 0.50)

## Interaction Contract

### Add Tracks (LIB-01)

1. User clicks `[+]` button in toolbar OR uses Alt+E (if panel not open, open first)
2. NSOpenPanel opens: `allowsMultipleSelection = true`, `allowedContentTypes = [.mp3]`
3. On confirm: `PlaylistManager.add(urls:)` is called
4. Table reloads with new rows appended at bottom
5. NSTableView scrolls to reveal the last newly added row

### Drag-Reorder (LIB-02)

1. User clicks and holds a row — drag begins after system drag threshold
2. Dragged row moves with cursor (NSTableView default drag proxy)
3. Drop indicator line appears between destination rows during hover
4. On drop: `PlaylistManager.move(from:to:)` is called, table reloads the moved rows
5. If the moved row is the active track: ▶ marker follows it to the new position

### Remove Track (LIB-04)

Three trigger paths, same outcome:
1. Delete key on selected row
2. Right-click context menu → "Remove from Playlist"
3. `[−]` toolbar button on selected row

Confirmation: none required (playlist is mutable and persistable; no file is deleted from disk).
If removed track is currently playing: advance to next track immediately. If last track: stop playback.

### Double-Click Row (CONTEXT.md D-14)

1. Double-click fires `tableView(_:shouldSelectRow:)` then action
2. `manzo_close` called on current handle
3. `PlaylistManager.currentIndex` set to clicked row
4. `manzo_open` + `manzo_play` called with new path
5. Active row marker updates immediately; previous ▶ is cleared

### Co-Move (CONTEXT.md D-03)

1. `NSWindowDidMoveNotification` observed on `ManzoWindow`
2. Delta computed: `newMainOrigin − oldMainOrigin`
3. Panel frame updated: `panelOrigin += delta`
4. No animation — movement is instantaneous and synchronous with the main window drag

### Panel Show/Hide (CONTEXT.md D-02)

- Alt+E: menu item in main menu "Playlist Editor" with `keyEquivalent: "e"` and `.option` modifier
- PL button: direct `orderFront(_:)` / `orderOut(_:)` on `ManzoPlaylistPanel`
- Panel open/closed state persists via `setFrameAutosaveName("ManzoPlaylistPanel")` — AppKit autosave encodes both position AND visibility for NSPanel

| Element | Copy |
|---------|------|
| Primary CTA (add tracks) | "Add Files…" — used in NSOpenPanel button and as tooltip for [+] |
| Toolbar add button label | "+" (bare plus sign, no text) |
| Toolbar add button tooltip | "Add Files…" |
| Toolbar remove button label | "−" (U+2212 minus sign, not hyphen) |
| Toolbar remove button tooltip | "Remove Selected Track" |
| Track count label (N = 0) | "0 tracks" |
| Track count label (N = 1) | "1 track" (singular) |
| Track count label (N > 1) | "N tracks" |
| Empty state heading | "No tracks" |
| Empty state body | "Add tracks with + or drag files here." |
| Missing-file tooltip | "File not found: {filename}" — `NSView.toolTip` on the row |
| Right-click menu item | "Remove from Playlist" |
| Menu bar item | "Playlist Editor" (under View menu or Window menu) |
| Destructive confirmation | None — see rationale above. No confirmation dialog for track removal. |
| Error: NSOpenPanel canceled | No error shown. Silent cancel is the correct behavior. |
| Error: ID3 read failure | No inline error. Track is added with filename fallback ("Unknown – {filename}") and duration shown as "–:––" until AVFoundation resolves it on the background queue. |

## Empty State

When `PlaylistManager.tracks.isEmpty`:

- NSTableView is hidden
- An `NSTextField` centered in `bodyView` displays:
  - Line 1: "No tracks" — 13 pt regular, P3(0.78, 0.80, 0.85, 0.70)
  - Line 2: "Add tracks with + or drag files here." — 11 pt regular, P3(0.78, 0.80, 0.85, 0.45)
  - Vertical alignment: centered in bodyView
  - Horizontal alignment: centered
- Toolbar remains fully visible so `[+]` is always accessible
- No illustration, no icon — text-only, consistent with Winamp's minimal empty state
