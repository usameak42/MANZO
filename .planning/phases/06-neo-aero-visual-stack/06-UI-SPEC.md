# Phase 6 — UI Design Contract: Neo-Aero Visual Stack

> Visual and interaction contract for the MANZO Neo-Aero chrome phase.
> Generated by gsd-ui-researcher. This is a VISUAL DECORATION phase — no new NSViews.
> All structural layout (panels, window geometry, drag) was locked in Phase 5.
> Phase 6 inserts CAGradientLayer sublayers into the existing panel layer trees.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — native Swift/AppKit (no web component library) |
| Preset | not applicable |
| Component library | AppKit + Core Animation (CALayer, CAGradientLayer, CAReplicatorLayer) |
| Icon library | none in Phase 6 |
| Font | none in Phase 6 (no new text elements — see Typography section) |

**Rationale:** MANZO is a native macOS AppKit application targeting macOS 26+. All rendering
is done via Core Animation layer API. shadcn, web design tokens, and icon libraries do not apply.
The "design system" for this phase is the CALayer API contract and the P3 brand palette.

## Color Contract

**All brand colors MUST use `CGColor(colorSpace: .displayP3)`. Never use `NSColor(calibratedRed:...)` or the sRGB `CGColor(red:green:blue:alpha:)` initializer for any color in this palette. (D-05, VIS-03)**

### P3 Color Construction Pattern (required for all colors below)

```swift
let p3 = CGColorSpace(name: CGColorSpace.displayP3)!
let color = CGColor(colorSpace: p3, components: [r, g, b, a])
```

## Layer Architecture (non-standard section — critical for this phase)

### 5-Layer Neo-Aero Stack Spec

Each Neo-Aero panel chrome consists of 5 layers inside a container `CALayer`. Layer order
(bottom to top): container wraps [base, specular, lowerGlow, rim]; wet-floor is a sibling
below via `CAReplicatorLayer`.

```
container (CALayer, masksToBounds=true, cornerRadius=10, shouldRasterize=true, rasterizationScale=2.0)
├── [1] base          CAGradientLayer   — full bounds, cornerRadius=10, 2-stop linear gradient
├── [2] specular      CAGradientLayer   — top 52% of bounds, 3-stop linear (white 50%→8%→0%)
├── [3] lowerGlow     CAGradientLayer   — bottom 25% of bounds, 2-stop linear (0%→12%)
└── [4] rim           CALayer           — bounds.insetBy(dx:0.5, dy:0.5), cornerRadius=9.5,
                                          borderWidth=1.0, borderColor=white@45%
```

**Layer 5 (wet-floor):** `CAReplicatorLayer` inserted as a sublayer of the root
`NSVisualEffectView`'s layer, positioned below the window bounds. Not inside the container.

---

### Frame Geometry per Layer

| Layer | Frame formula | Note |
|-------|--------------|-------|
| `container` | `bounds` of target panel view | Full panel coverage |
| `base` | `container.bounds` | Same as container |
| `specular` | `CGRect(x:0, y:0, width:bounds.width, height:bounds.height * 0.52)` | Top 52% |
| `lowerGlow` | `CGRect(x:0, y:bounds.height*0.75, width:bounds.width, height:bounds.height*0.25)` | Bottom 25% |
| `rim` | `bounds.insetBy(dx:0.5, dy:0.5)` | Inset by 0.5pt all sides |

For `.unifiedSlab`: `bounds` = `{0, 0, 275, 116}` (full root view bounds, not individual panel bounds).
For `.threeBubbles`: `bounds` per panel — `titleView` = `{0,0,275,14}`, `bodyView` = `{0,0,275,88}`, `statusView` = `{0,0,275,14}`.
For `.bodyFocus`: `bodyView` uses full 5-layer stack; `titleView` and `statusView` use base+rim only (2 layers).

### CAReplicatorLayer Wet-Floor Spec (D-06)

Applies only when `ManzoVisualStyle.wetFloor == true`.

| Property | Value |
|----------|-------|
| `instanceCount` | `2` |
| `instanceTransform` | Y-flip: `CATransform3D(m11:1,m12:0,m13:0,m14:0, m21:0,m22:-1,m23:0,m24:0, m31:0,m32:0,m33:1,m34:0, m41:0,m42:kWindowHeight*2,m43:0,m44:1)` |
| `instanceAlphaOffset` | `-0.5` (reflection at 50% opacity) |
| `mask` | `CAGradientLayer`, colors `[black@1.0, black@0.0]`, frame = `reflectionRect` |
| Insertion point | Sublayer of `ManzoRootView.layer` (root NSVisualEffectView layer), positioned below window bounds |
| Creation/removal | Create when `wetFloor` becomes `true`; remove (not hide) when `false` (D-07) |

**Performance:** Zero CPU per-frame. GPU-only. Automatically tracks panel position during window drag.

### PanelLayout Mode Specs (D-03)

#### `.unifiedSlab` (default)

One `NeoAeroLayerFactory.make(style:bounds:)` call with `bounds = rootView.bounds` (`{0,0,275,116}`).
Resulting container layer is added as a sublayer of `ManzoRootView.layer` (below panel NSViews).
`titleView`, `bodyView`, `statusView` remain as layout/interaction zones above the chrome.

Layer insertion:
```swift
// Insert below panel views so panels receive hit-testing
rootView.layer?.insertSublayer(neoAeroLayer, at: 0)
```

#### `.threeBubbles`

Three separate `NeoAeroLayerFactory.make(style:bounds:)` calls — one per panel:
- `titleView.layer?.addSublayer(...)` with `bounds = {0,0,275,14}`
- `bodyView.layer?.addSublayer(...)` with `bounds = {0,0,275,88}`
- `statusView.layer?.addSublayer(...)` with `bounds = {0,0,275,14}`

Note on 14pt panels: `specular` height = `14 * 0.52 = 7.3 pt` — renders correctly (tight but visible).

#### `.bodyFocus`

- `bodyView`: full 5-layer stack, `bounds = {0,0,275,88}`
- `titleView`: base + rim only (2 layers, `cornerRadius = 0`)
- `statusView`: base + rim only (2 layers, `cornerRadius = 0`)

```swift
// bodyFocus — titleView and statusView get simplified 2-layer stack
let simplified = NeoAeroLayerFactory.makeSimplified(style:, bounds:)
titleView.layer?.addSublayer(simplified)
```

### Rasterization Contract (D-08, VIS-04)

| Setting | Value | Rule |
|---------|-------|-------|
| `shouldRasterize` | `true` | Set on `container` layer only (not on sub-layers) |
| `rasterizationScale` | `2.0` | Always set alongside `shouldRasterize = true` — never omit on Retina |
| Invalidation trigger | Theme switch, layout switch, drag-end | Set `shouldRasterize = false` then `true` |
| Per-frame invalidation | FORBIDDEN | Do not call outside the three triggers above |
| `masksToBounds` mitigation | Handled by `shouldRasterize = true` | `masksToBounds = true` off-screen rendering becomes one-time cost |

Performance gate: 30+ static Neo-Aero elements at GPU compositing time < 0.8 ms on M1 (spike 008 verified).

### Factory API Contract (D-09)

New file: `ManzoApp/ManzoApp/NeoAeroLayer.swift`

```swift
// Required public surface
struct NeoAeroLayerFactory {
    static func make(style: ManzoVisualStyle, bounds: CGRect) -> CALayer
    static func makeSimplified(style: ManzoVisualStyle, bounds: CGRect) -> CALayer
    // makeSimplified: base + rim only, no specular/lowerGlow, cornerRadius=0
}
```

Returns a root `CALayer` (the `container`) ready for `addSublayer`. Does not mutate any view.

### ManzoVisualStyle Contract (D-02, D-03, D-04)

New file: `ManzoApp/ManzoApp/ManzoThemeController.swift` (or merged into AppDelegate — Claude's Discretion)

```swift
struct ManzoVisualStyle: Codable {
    var panelLayout: PanelLayout  // .unifiedSlab | .threeBubbles | .bodyFocus
    var colorTheme:  ColorTheme   // .winampClassic | .neoAero | .indigoTeal | .wszSkin
    var wetFloor:    Bool

    static let `default` = ManzoVisualStyle(
        panelLayout: .unifiedSlab,
        colorTheme:  .winampClassic,
        wetFloor:    false
    )
}

enum PanelLayout: String, Codable {
    case unifiedSlab   // default
    case threeBubbles
    case bodyFocus
}

enum ColorTheme: String, Codable {
    case winampClassic  // default
    case neoAero
    case indigoTeal
    case wszSkin        // v2 placeholder — no implementation
}
```

Persistence: `UserDefaults`. Key naming: Claude's Discretion.

Style application: `ManzoRootView.applyStyle(_ style: ManzoVisualStyle)` — removes existing
neo-aero sublayers, rebuilds via `NeoAeroLayerFactory`, re-inserts. No full view teardown.
