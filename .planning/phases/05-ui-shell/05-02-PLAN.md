<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UserDefaults (frame autosave) | AppKit writes window frame (origin + size) to UserDefaults under the autosave name key |
| NSApplication.shared | AppDelegate is the delegate — receives all application lifecycle events |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04 | Tampering | UserDefaults window frame autosave | accept | UserDefaults for window position stores only NSRect (x, y, width, height). No executable content, no PII. A malicious UserDefaults value could misplace the window off-screen — AppKit's setFrameAutosaveName has built-in screen-boundary recovery via ensureVisibleOnScreen. Low impact, no mitigation needed. |
| T-05-05 | Spoofing | ManzoWindow as key/main window | accept | canBecomeKey=true allows this window to receive keyboard events — intended behavior for a music player. No elevated privilege or sensitive data flow through keyboard input in Phase 5. |
| T-05-06 | Denial of Service | ARC deallocation of ManzoWindow | mitigate | Window is retained in `private var manzoWindow: ManzoWindow?` on AppDelegate. Without this ivar, the window deallocates immediately after applicationDidFinishLaunching returns (local var goes out of scope). Mitigation: ivar retention is specified in the task action. |
| T-05-07 | Information Disclosure | NSLog frame autosave output | accept | NSLog prints the autosave name string literal "ManzoMainWindow" — no sensitive data. Visible only to device owner in Console.app. |
</threat_model>
