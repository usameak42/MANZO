5. **manzo_open implementation**:
- Guard: if path.is_null() → return null_mut()
- `CStr::from_ptr(path).to_str()` → on error return null_mut()
- Read file into `Vec<u8>` via `std::fs::read(path_str)` → on error return null_mut()
- Init mpg123: `mpg123_sys::mpg123_new(std::ptr::null(), &mut err)` → on error return null_mut()
- Set float32 output: `mpg123_sys::mpg123_param(mh, mpg123_sys::MPG123_FLAGS, mpg123_sys::MPG123_FORCE_FLOAT as i64, 0.0)` — CRITICAL: must set MPG123_FORCE_FLOAT flag or output will not be float32
- `mpg123_sys::mpg123_open_feed(mh)` → on non-zero return, null_mut()
- Feed first chunk: `mpg123_sys::mpg123_feed(mh, file_data.as_ptr(), FEED_CHUNK_SIZE.min(file_data.len()))`

6. **manzo_close implementation**:

7. **manzo_play implementation**:
- Guard: null handle → return -1 (D-04)
- Cast: `let arc = &*(handle as *mut Arc<Mutex<InnerState>>);`
- Lock: `let state = arc.lock().unwrap_or_else(|e| e.into_inner());`
- If already playing: return 0 (idempotent)
- Get cpal default output device: `cpal::default_host().default_output_device()` → return -1 on None
- Get default output config: `device.default_output_config()` → return -1 on error
- Use `cpal::StreamConfig { channels: state.channels, sample_rate: cpal::SampleRate(state.sample_rate), buffer_size: cpal::BufferSize::Default }`
- Clone the Arc for the callback: `let inner_clone = Arc::clone(arc);`
- Build stream with `device.build_output_stream`:
  ```rust
  move |data: &mut [f32], _: &cpal::OutputCallbackInfo| {
      if let Ok(mut s) = inner_clone.lock() {
          if !s.is_playing { 
              data.fill(0.0); 
              return; 
          }
          let mut written = 0usize;
          while written < data.len() {
              let mut done = 0usize;
              let buf_len = (data.len() - written) * 4;  // f32 = 4 bytes
              // SAFETY: data[written..] is valid f32 slice
              let ret = unsafe {
                  mpg123_sys::mpg123_read(
                      s.mpg_handle,
                      data[written..].as_mut_ptr() as *mut u8,
                      buf_len,
                      &mut done,
                  )
              };
              let frames_written = done / 4;
              written += frames_written;
              s.position_samples += frames_written as u64 / s.channels as u64;
              if ret == mpg123_sys::MPG123_NEED_MORE as i32 {
                  // Feed next chunk from file_data
                  let end = (s.file_offset + FEED_CHUNK_SIZE).min(s.file_data.len());
                  if s.file_offset < s.file_data.len() {
                      unsafe {
                          mpg123_sys::mpg123_feed(
                              s.mpg_handle,
                              s.file_data[s.file_offset..end].as_ptr(),
                              end - s.file_offset,
                          );
                      }
                      s.file_offset = end;
                  } else if frames_written == 0 {
                      // EOF — fill remainder with silence
                      data[written..].fill(0.0);
                      break;
                  }
              } else if ret != 0 && frames_written == 0 {
                  data[written..].fill(0.0);
                  break;
              }
          }
      } else {
          data.fill(0.0);
      }
  }
  ```
  Error callback: `|err| eprintln!("cpal stream error: {err}")`
  Timeout: `None`
- Call `stream.play()` → return -1 on error
- Store stream: re-lock, set state.stream = Some(stream), state.is_playing = true
- Return 0

- Return 0 on success, -1 on mpg123 error

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Swift/UI → FFI (manzo_open path arg) | Untrusted C string from Swift; must be validated before use |
| FFI → ManzoHandle raw pointer | Caller-owned opaque pointer; null or dangling pointer possible |
| cpal audio callback → InnerState | Cross-thread access; protected by Arc&lt;Mutex&gt; but mutex poisoning must be handled |
| manzo_get_spectrum → out_buf | Caller-provided buffer pointer; out-of-bounds write possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Elevation of Privilege | manzo_open path injection | mitigate | Validate C string via CStr::from_ptr → to_str() before any filesystem access; reject null path immediately (return null_mut()) |
| T-02-04 | Denial of Service | manzo_open null path | mitigate | Null-check is the first guard before CStr::from_ptr — CStr::from_ptr(null) is UB; guard must precede it |
| T-02-05 | Tampering | ManzoHandle null dereference | mitigate | Every FFI function that takes *mut ManzoHandle performs `if handle.is_null() { return safe_sentinel; }` as first statement |
| T-02-06 | Tampering | manzo_get_spectrum out_buf overrun | mitigate | Guard: `if out_buf.is_null() \|\| count == 0 { return 0; }` — write exactly `count` f32 zeros via write_bytes, no bounds exceeded |
| T-02-07 | Denial of Service | ManzoHandle resource leak | mitigate | manzo_close calls Box::from_raw to take ownership and drop; InnerState implements Drop to call mpg123_delete; cpal Stream drops automatically |
| T-02-08 | Denial of Service | Mutex poisoning in audio callback | mitigate | Use `lock().unwrap_or_else(\|e\| e.into_inner())` to recover poisoned mutex and fill silence rather than panic |
</threat_model>
