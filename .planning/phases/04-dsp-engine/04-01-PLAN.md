Key constants (from eq10dsp.h):
  EQ10_Q            = 1.41    (f64)
  EQ10_NOFBANDS     = 10
  EQ10_TRIM_CODE    = 0.930   (limiter threshold)
  EQ10_TRIM_RELEASE = 0.700   (seconds; used in detectdecay formula)
  DENORMAL_FIX      = 1e-30_f64 (added to y0 and detect in sample loops)
  EQ10_DETECTOR_CODE is NOT defined in shipped Winamp — do NOT port per-band detect/detectdecay

Winamp frequency table (EQ_FREQUENCIES_WINAMP, hardcoded for v1):
  [70.0, 180.0, 320.0, 600.0, 1000.0, 3000.0, 6000.0, 12000.0, 14000.0, 16000.0] Hz

Struct layout (eq10dsp.h lines 53-84 → Rust):
```rust
pub(crate) struct Eq10Band {
    pub gain: f64,                             // shifted-linear; 0.0 == 0 dB
    pub ua0: f64, pub ub1: f64, pub ub2: f64,  // boost coefficients (Q*2)
    pub da0: f64, pub db1: f64, pub db2: f64,  // cut coefficients (Q*0.5)
    pub x1: f64, pub x2: f64,                 // input delay line
    pub y1: f64, pub y2: f64,                 // output delay line
}

pub(crate) struct Eq10State {
    pub rate: f64,
    pub band: [Eq10Band; 10],
    pub detect: f64,       // global limiter peak tracker (EQ10_TRIM_CODE threshold)
    pub detectdecay: f64,  // pow(0.001, 1/(rate * 0.700)) — computed in ::new(), NOT default
}
```

Critical init rule: detectdecay MUST be computed as `0.001_f64.powf(1.0 / (rate * 0.700))`.
Never use Default or zero-initialize — detectdecay=0.0 causes the limiter to never fire (Pitfall 4).

eq10_bsetup2 (eq10dsp.cpp lines 36-77):
  - Called twice per band: cut first (boost=false, q*0.5), boost second (boost=true, q*2.0)
  - Nyquist guard: if freq >= rate*0.499 → set ua0=0, da0=0, return early
  - angle = 2π * freq / rate
  - alpha = sin(angle) / (2*q)
  - b0 = 1/(1+alpha)
  - a0 = b0 * alpha
  - b1 = b0 * 2 * cos(angle)
  - b2 = b0 * (alpha - 1)
  - boost=true  → band.ua0=a0, band.ub1=b1, band.ub2=b2
  - boost=false → band.da0=a0, band.db1=b1, band.db2=b2

eq10_bsetup (eq10dsp.cpp lines 68-77):
  - Resets band to all-zeros first (memset equivalent)
  - Then calls eq10_bsetup2(false, rate, band, freq, q*0.5)  // cut
  - Then calls eq10_bsetup2(true,  rate, band, freq, q*2.0)  // boost

eq10_processf critical details (eq10dsp.cpp lines 98-206):
  - sz = number of FRAMES (not samples); inner loop: i = idx + t*step
  - gain > 0.0  → use boost coefficients (ua0*gain, ub1, ub2)
  - gain <= 0.0 → use cut coefficients   (da0*gain, db1, db2)
  - if a0 == 0.0 { continue; }  — skip band entirely (BOTH correctness and perf optimization)
  - Biquad formula: y0 = (x - x2)*a0 + y1*b1 + y2*b2 + 1e-30  (DENORMAL_FIX)
  - Output: buf[i] = (y0 + x) as f32  — peaking EQ: add filtered delta to original input
  - State update order: x2=x1; x1=x; y2=y1; y1=y0  (after computing y0)
  - In-place cascade: next band reads same buf (no pointer reset needed)
  - Dynamic limiter (after all 10 bands):
      detect tracks abs peak; scale if detect > 0.930
      buf[i] = if detect > 0.930 { (s * 0.930/detect) as f32 } else { s as f32 }
      detect *= detectdecay; detect += 1e-30  (DENORMAL_FIX)
      store eq.detect = detect after loop

eq10_db2gain (eq10dsp.cpp lines 208-211):
  10.0_f64.powf(gain_db / 20.0) - 1.0
  // 0 dB → 0.0; +12 dB → ≈2.981; -12 dB → ≈-0.749

**eq10_bsetup2(boost: bool, rate: f64, band: &mut Eq10Band, freq: f64, q: f64):**
```
let rate = rate.clamp(4000.0, 384000.0);
let freq = freq.max(20.0);
if freq >= rate * 0.499 {
    band.ua0 = 0.0; band.da0 = 0.0;
    return;
}
let angle = 2.0 * std::f64::consts::PI * freq / rate;
let alpha = angle.sin() / (2.0 * q);
let b0 = 1.0 / (1.0 + alpha);
let a0 = b0 * alpha;
let b1 = b0 * 2.0 * angle.cos();
let b2 = b0 * (alpha - 1.0);
if boost {
    band.ua0 = a0; band.ub1 = b1; band.ub2 = b2;
} else {
    band.da0 = a0; band.db1 = b1; band.db2 = b2;
}
```

**eq10_processf — hot path (verbatim from eq10dsp.cpp lines 98-206, in-place Rust port):**
```
// sz = number of FRAMES; idx = channel offset (0 or 1); step = 2 (stereo)
// 10-band cascade
for k in 0..10 {
    let band = &mut eq.band[k];
    let gain = band.gain;
    let (a0, b1, b2) = if gain > 0.0 {
        (band.ua0 * gain, band.ub1, band.ub2)   // boost branch (gain > 0)
    } else {
        (band.da0 * gain, band.db1, band.db2)   // cut branch (gain <= 0)
    };
    if a0 == 0.0 { continue; }  // skip flat band — source line 139

    let mut x1 = band.x1; let mut x2 = band.x2;
    let mut y1 = band.y1; let mut y2 = band.y2;
    for t in 0..sz {
        let i = idx + t * step;
        let x = buf[i] as f64;
        let y0 = (x - x2) * a0 + y1 * b1 + y2 * b2 + 1e-30_f64;  // DENORMAL_FIX
        x2 = x1; x1 = x; y2 = y1; y1 = y0;
        buf[i] = (y0 + x) as f32;   // peaking EQ: filtered delta added to input
    }
    band.x1 = x1; band.x2 = x2; band.y1 = y1; band.y2 = y2;
    // in-place: buf IS outbuf — cascade is automatic (Pitfall 1 avoidance)
}

// Dynamic limiter — EQ10_TRIM_CODE=0.930, EQ10_TRIM_RELEASE=0.700
// (copy-only else-if from source lines 200-204 is omitted — in-place port only)
if config_eq_limiter {
    let mut detect = eq.detect;
    let detectdecay = eq.detectdecay;
    for t in 0..sz {
        let i = idx + t * step;
        let s = buf[i] as f64;
        let abs_s = s.abs();
        if abs_s > detect { detect = abs_s; }
        buf[i] = if detect > 0.930 {
            (s * (0.930 / detect)) as f32
        } else {
            s as f32
        };
        detect *= detectdecay;
        detect += 1e-30_f64;  // DENORMAL_FIX
    }
    eq.detect = detect;
}
```
