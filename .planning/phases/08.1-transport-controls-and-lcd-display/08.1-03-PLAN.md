**Step 2: Add `relocateSpectrumView()` method.**
This method updates the ManzoSpectrumView constraints from the existing Phase 7 layout (225×32, centered, bottomAnchor) to the Phase 8.1 Winamp viz band (107×32, topAnchor+43, leadingAnchor). Call it after the spectrum is already added.

```swift
// MARK: - Phase 8.1: Spectrum View Relocation (D-03)

/// Relocates the spectrum from Phase 7's bottom-anchored layout to Winamp's viz band.
/// Must be called AFTER addSpectrumView has added the view to bodyView.
/// New position: bodyView.topAnchor + 43 → height=32, width=107, leading edge (D-03).
func relocateSpectrumView() {
    guard let sv = spectrumView else {
        NSLog("MANZO Phase 8.1: ManzoRootView.relocateSpectrumView — spectrumView is nil, skipping")
        return
    }
    // Remove ALL existing constraints on sv that are owned by sv's superview.
    // NSLayoutConstraint.deactivate works even for constraints created by the superview.
    sv.removeConstraints(sv.constraints)
    // Also remove superview-owned constraints referencing sv (Phase 7 created these in addSpectrumView).
    if let superConstraints = sv.superview?.constraints {
        let toRemove = superConstraints.filter { c in
            c.firstItem as? NSView == sv || c.secondItem as? NSView == sv
        }
        NSLayoutConstraint.deactivate(toRemove)
    }

    // Apply new Winamp viz band constraints (D-03):
    // topAnchor = bodyView.topAnchor + 43, height=32, width=107, leadingAnchor = bodyView.leadingAnchor
    NSLayoutConstraint.activate([
        sv.topAnchor.constraint(equalTo: bodyView.topAnchor, constant: 43),
        sv.heightAnchor.constraint(equalToConstant: 32),
        sv.widthAnchor.constraint(equalToConstant: 107),
        sv.leadingAnchor.constraint(equalTo: bodyView.leadingAnchor),
    ])

    // UI-SPEC note 10: must call layoutSubtreeIfNeeded BEFORE applySpectrumChromeMask,
    // otherwise spectrumFrame is CGRect.zero.
    bodyView.layoutSubtreeIfNeeded()
    applySpectrumChromeMask(spectrumFrame: sv.frame)

    NSLog("MANZO Phase 8.1: ManzoRootView.relocateSpectrumView — spectrum at bodyView.topAnchor+43, 107×32pt")
}
```

Note: `applySpectrumChromeMask` is currently `private`. To call it from `relocateSpectrumView`, either:

(b) Place `relocateSpectrumView` in the same source file extension section (it is, since ManzoRootView.swift is a single class). Since they are in the same class body, the private method IS accessible — no change needed.

**ADDITION 3: Extend pollPlaybackState() with four new steps (D-12)**

The current `pollPlaybackState` structure is:
```swift
@objc private func pollPlaybackState() {
    guard let handle = manzoHandle else { return }
    let state = manzo_get_state(handle)
    guard state == MANZO_STATE_ENDED else { return }
    // ... ENDED branch (advance to next track) ...
}
```

The `guard state == MANZO_STATE_ENDED else { return }` pattern means the ENDED branch IS the fall-through, and the non-ENDED case hits `return`. To add the four poll steps for the non-ENDED case, change the guard to use the else branch:

```swift
@objc private func pollPlaybackState() {
    guard let handle = manzoHandle else { return }

    let state = manzo_get_state(handle)

    // Phase 8.1 (D-12): four poll steps run on every non-ENDED tick.
    guard state == MANZO_STATE_ENDED else {
```
