## Control Layout

| Option | Description | Selected |
|--------|-------------|----------|
| Relocate spectrum upward | Move spectrum to y=57–87 (Winamp viz area). All new controls at canonical Winamp pixel positions. | ✓ |
| Stack above spectrum | Keep spectrum at bottom, cram controls into 56pt above it. | |
| Hybrid: shrink spectrum | Reduce spectrum height to 20pt, match Winamp spacing. | |

**User's choice:** Relocate spectrum upward — follow Winamp's exact layout as canonical reference.
**Notes:** User explicitly requested checking Winamp source (`draw_main.cpp`) for pixel positions before discussing layout. Positions extracted and tabulated from `draw_buttonbar`, `draw_positionbar`, `draw_volumebar`, `draw_panbar`, `draw_time`, `draw_bitmixrate`, `draw_monostereo`.

## LCD Display — Rendering Approach

| Option | Description | Selected |
|--------|-------------|----------|
| Custom NSView | ManzoLCDView subclass, black CALayer background, CATextLayer per field. | ✓ |
| NSTextField | Multiple NSTextField instances with green text, black background. | |

**Notes:** Matches established CALayer-only pattern from Phase 6. Five named CATextLayer fields: titleLayer, timeLayer, bitrateLayer, kHzLayer, stereoLayer.

## LCD Display — Time Display Mode

| Option | Description | Selected |
|--------|-------------|----------|
| Elapsed only | Always shows MM:SS elapsed. Simpler. | |
| Elapsed + total both | Shows e.g. "3:21 / 5:00". | |
| Toggleable (Winamp-faithful) | Click time area to toggle between elapsed/remaining. | ✓ |

**User's choice:** Toggleable — click on timeLayer to switch between elapsed and remaining.
**Notes:** Matches Winamp's `config_timeleftmode` behavior. Requires NSTrackingArea on ManzoLCDView and a boolean state flag.

---

## LCD Display — Title Scrolling

| Option | Description | Selected |
|--------|-------------|----------|
| Timer-based pixel shift | Use existing 100ms poll timer tick. Shift layer by 0.5pt/tick. | ✓ |
| CAAnimation keyframe | CABasicAnimation on layer.position.x. Independent of poll timer. | |

**User's choice:** Timer-based pixel shift — reuse existing 100ms poll timer.
**Notes:** Avoids a second timer. 0.5pt per 100ms = 5pt/second scroll rate. Winamp used similar pixel-per-frame scrolling.

## Interactive Controls — Seek Interaction

| Option | Description | Selected |
|--------|-------------|----------|
| Seek on mouse-up only | Visual tracking during drag, FFI call only on release. | |
| Live seek while dragging | Call manzo_seek() on every mouseDragged event. | ✓ |

**User's choice:** Live seek while dragging.
**Notes:** User accepted the risk of rapid-fire FFI seeks. ManzoSeekBar uses a `isDragging` flag so the 100ms poll timer doesn't reset the thumb while the user is dragging.
