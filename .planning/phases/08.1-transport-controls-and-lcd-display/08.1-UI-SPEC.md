## Spacing Scale

Pixel values are fixed to Winamp's canonical `draw_main.cpp` coordinates (D-01).
The standard 8-point grid applies to inter-element gaps; Winamp pixel positions
govern absolute placement.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 pt | Intra-label gap (bitrate ↔ kHz text within the LCD area) |
| sm | 8 pt | PL button right inset (Phase 8 established); window-edge inset for seek bar (x=16) |
| md | 16 pt | — |
| lg | 24 pt | — |

Exceptions:
- All Phase 8.1 controls are absolutely positioned using Winamp pixel coords from D-01.
  NSLayoutAnchor constants are set to the exact pt values in D-01 — not snapped to the 8-pt grid.
- Touch-target minimum (44 pt) does NOT apply — this is a precision desktop app targeting
  mouse/trackpad only on macOS. Controls match Winamp's compact 23×18 and 10-pt dimensions exactly.
- LCD area placed at topAnchor + 14 (titleView height), height = 43 pt — from D-04.
- Transport buttons: 23×18 pt each (Prev, Play, Stop, Next) — from D-09.
- Seek bar: 248×10 pt at y=72 — from D-07.

## Typography

All text is rendered via CATextLayer (not NSTextField or NSAttributedString labels).
Fonts use NSFont APIs, converted to CGFont for CATextLayer via CTFontCreateWithName.

| Role | Font | Size | Weight | Line Height |
|------|------|------|--------|-------------|
| LCD time digits | NSFont.monospacedSystemFont | 8 pt | .medium (500) | 1.0 (fixed-height layer) |
| LCD bitrate / kHz / stereo | NSFont.monospacedSystemFont | 8 pt | .medium (500) | 1.0 |
| LCD title (scrolling) | NSFont.monospacedSystemFont | 8 pt | .regular (400) | 1.0 |
| Transport button label | NSFont.systemFont | 9 pt | .regular (400) | 1.0 |

Rules:
- CATextLayer must have `contentsScale = 2.0` (Retina) — set in initializer.
- CATextLayer font set via `font = NSFont.monospacedSystemFont(ofSize: 8, weight: .medium) as CTFont`.
- No attributed strings — plain string assignment to `string` property.
- `truncationMode = .end` on titleLayer (scrolling overrides this in practice).
- `alignmentMode = .left` on all LCD text layers.

## Color

Source: CONTEXT.md D-04, D-07, D-08, D-09 and NeoAeroLayer.swift (established palette).
All colors constructed via `CGColorSpace(name: CGColorSpace.displayP3)!` (VIS-03 / CLAUDE.md constraint).

| Role | P3 Components (r, g, b, a) | Usage |
|------|--------------------------|-------|
| LCD background | (0.0, 0.0, 0.0, 1.0) — pure black | ManzoLCDView.layer.backgroundColor; seek bar background; slider background |
| LCD green (standard) | (0.18, 0.82, 0.18, 1.0) | All CATextLayer foregroundColor; seek bar fillLayer; slider fillLayer; transport button label |
| LCD green (bright) | (0.30, 0.95, 0.30, 1.0) | Seek bar thumbLayer; slider thumbLayer (brighter to visually distinguish) |
| NeoAero chrome (winampClassic base top) | (0.09, 0.09, 0.16, 1.0) | Transport button NeoAeroLayerFactory base gradient top — pre-existing |
| NeoAero chrome (winampClassic base bottom) | (0.22, 0.22, 0.35, 1.0) | Transport button NeoAeroLayerFactory base gradient bottom — pre-existing |
| Rim highlight | (1.0, 1.0, 1.0, 0.45) | Transport button rim border — pre-existing from NeoAeroLayerFactory |
| Specular top | (1.0, 1.0, 1.0, 0.50) | Transport button specular band — pre-existing |

Color application split (60/30/10):
- 60% dominant: LCD black background surfaces (ManzoLCDView, seek bar, sliders)
- 30% secondary: NeoAero chrome on transport buttons (base gradient dark navy/indigo)
- 10% accent: LCD green — reserved for: time digits, title text, bitrate/kHz labels, stereo label, seek bar fill, seek bar thumb, slider fill, slider thumb, transport button unicode labels

Destructive color: not applicable — no destructive actions in this phase.

### Construction Pattern (mandatory)

```swift

let lcdBlack  = CGColor(colorSpace: p3, components: [0.0,  0.0,  0.0,  1.0])!
```

## Interaction Contract

### ManzoLCDView

| Target | Event | Response |
|--------|-------|----------|
| timeLayer (NSTrackingArea) | mouseDown | Toggle `isShowingRemaining: Bool` — next poll tick updates timeLayer.string |
| titleLayer | no interaction | Display only; scroll is timer-driven |

### ManzoSeekBar

| Event | Response |
|-------|----------|
| mouseDown | Compute `t = event.x / 248.0 * duration`; call `manzo_seek(handle, t)`; set `isDragging = true` |
| mouseDragged | Compute `t`; call `manzo_seek(handle, t)` live — no debounce |
| mouseUp | Set `isDragging = false`; resume poll-driven fill update |

Poll timer behavior: if `isDragging == false`, update `fillLayer.frame.width = (position / duration) * 248` and `thumbLayer.frame.origin.x = fillLayer.frame.width - 1.5`.

### ManzoSlider

| Event | Response |
|-------|----------|
| mouseDown + mouseDragged | Compute normalized value; call `manzo_set_volume` or `manzo_set_pan` immediately |
| mouseUp | No action (value already committed) |

### ManzoTransportButton

| State | Visual Change |
|-------|--------------|
| Default | Full NeoAero glass stack, rim at alpha 0.45 |
| Hover | Rim highlight alpha reduced to 0.25 (subtract 0.2 per D-09) |
| Press | `shouldRasterize = false` then `shouldRasterize = true` to flash specular refresh (D-09) |

Play/Pause toggle (D-10):
- `MANZO_STATE_PLAYING (1)` → label = "⏸", action = `manzo_pause(handle)`
- `MANZO_STATE_PAUSED (2)` or `MANZO_STATE_STOPPED (3)` → label = "▶", action = `manzo_play(handle)`
- `MANZO_STATE_ENDED (4)` → label = "▶" (existing auto-advance handles track advancement)

### Title Scrolling (D-05)

- Scroll trigger: `titleLayer.frame.width > 154 pt` (i.e., text wider than display area)
- Scroll rate: 0.5 pt per poll tick (10fps → ~5 pt/sec, matching Winamp feel)
- Loop: when `titleLayer.frame.maxX < superlayer.bounds.minX` → reset to `superlayer.bounds.maxX`
- Separator: " *** " appended to title string for seamless loop
- Track change: reset scroll offset to 0, rebuild title string

### Time Toggle Display (D-06)

- Default: elapsed time from `manzo_get_position(handle)`, formatted "m:ss"
- Toggled: remaining time `-(duration - position)`, formatted "-m:ss"
- 100ms poll timer reads `isShowingRemaining` flag each tick

### Smart Prev (D-11)

```
if manzo_get_position(handle) > 2.0:
    manzo_seek(handle, 0.0)      // restart current track
else:
    playlistManager.prev()
    jumpToTrack(at: playlistManager.currentIndex)
```

### Poll Timer Extensions (D-12)

Existing `pollPlaybackState()` extended (not replaced) with these additions, in order:
1. Read `manzo_get_position` → update `ManzoSeekBar.currentPosition` if not dragging
2. Tick title scroll offset in `ManzoLCDView`
3. Update `timeLayer.string` per elapsed/remaining toggle
4. Update play/pause button label per `manzo_get_state`

## Component Layer Architecture

All new views follow the established CALayer-only pattern (SHELL-03):
- `translatesAutoresizingMaskIntoConstraints = false`
- `wantsLayer = true`
- No nested `NSVisualEffectView`
- `shouldRasterize = true` + `rasterizationScale = 2.0` on static layers (e.g., NeoAero chrome on transport buttons)
- `shouldRasterize = false` on animated layers (fillLayer, thumbLayer — they change size each frame)

### ManzoTransportButton Chrome

Use `NeoAeroLayerFactory.make(style:bounds:)` for the full 5-layer stack on all 7 buttons.
The 23×18 button size is small but the factory cornerRadius=10 produces a "pill" shape that
is visually appropriate for compact transport buttons. Do NOT use `makeSimplified` — the full
specular stack reads better at this scale.

Exception: Shuffle (47×15) and Repeat (28×15) placeholders may use `makeSimplified` to
visually de-emphasize their no-op status.

## Copywriting Contract

Source: CONTEXT.md + REQUIREMENTS.md. This phase has minimal copy — all elements are functional
indicators or status displays, not narrative UI.

| Element | Copy |
|---------|------|
| LCD title (no track loaded) | "" (empty string — LCD displays nothing) |
| LCD time (no track loaded) | "0:00" |
| LCD bitrate (no track loaded) | "---" |
| LCD kHz (no track loaded) | "--" |
| LCD stereo (no track loaded) | "" (empty) |
| LCD time (elapsed mode) | "m:ss" format, e.g. "1:23" |
| LCD time (remaining mode) | "-m:ss" format, e.g. "-1:23" |
| LCD title scroll separator | " *** " (Winamp canonical, from D-05 / `<specifics>`) |
| Pan center status text | "BALANCE" (optional, shown in titleLayer for 2s when pan resets to 0) |
| Shuffle button label | "SHF" |
| Repeat button label | "REP" |
| Eject button label | "⏏" |

Empty state: The LCD displays static placeholder dashes ("---", "--") and "0:00" when no
track is loaded. There is no "empty state heading" because this is not a list UI.

Error state: No error UI required in Phase 8.1. FFI errors are logged via `NSLog` only;
no visual error feedback is specified for this phase.

Destructive actions: None. Eject opens file picker (additive), no track deletion.

## Implementation Notes for Executor

These notes are constraints, not suggestions:

1. **No sRGB colors.** Every CGColor must use `CGColorSpace(name: CGColorSpace.displayP3)!`. Failure causes VIS-03 regression.

2. **One NSVisualEffectView maximum.** Do not add any new NSVisualEffectView for any Phase 8.1 view. SHELL-02 is absolute.

3. **CATextLayer contentsScale.** Set `contentsScale = window?.backingScaleFactor ?? 2.0` in `viewDidMoveToWindow` or similar — otherwise text is blurry on Retina.

4. **shouldRasterize pairing.** Every `shouldRasterize = true` requires `rasterizationScale = 2.0` in the same assignment block. No exceptions (CLAUDE.md constraint).

5. **Animated layers must NOT rasterize.** `fillLayer` and `thumbLayer` change width/x on every poll tick. Do not set `shouldRasterize = true` on them.

6. **NSLayoutAnchor for all frames.** Use `NSLayoutAnchor` constants from D-01 for all view frames. No `setFrame:` on constraint-managed views.

7. **No NIBs or storyboards.** All views are code-only (established project pattern).

8. **NSLog for all diagnostic output.** Use `NSLog("MANZO Phase 8.1: ...")` prefix for all new log lines.

9. **NeoAeroLayerFactory.make bounds.** Pass the button's final frame as `bounds:` — not `frame:` (both are CGRect but `frame` is in superview coords; `bounds` is self-origin at zero). Use `CGRect(origin: .zero, size: button.frame.size)`.

10. **Spectrum chrome mask.** After relocating ManzoSpectrumView, call `bodyView.layoutSubtreeIfNeeded()` before `applySpectrumChromeMask` — without it the frame is CGRect.zero.
