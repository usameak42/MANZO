## Decisions Made

- `applySpectrumChromeMask` remains `private` — Swift allows private access within the same class body, so `relocateSpectrumView` in the same file can call it directly with no modifier change needed.
- `pollPlaybackState` restructured with `guard state == MANZO_STATE_ENDED else { ... return }` pattern — the non-ENDED branch runs all 4 poll steps then returns; the ENDED auto-advance branch below is completely unchanged.
- Play/pause button label is set optimistically on button press (immediate feedback); the poll timer at 100ms corrects it to actual state — no need to re-read manzo_get_state after the action call.
- Bitrate/kHz defaults of 128/44 kbps used in lcdView?.updateTrack calls — PlaylistTrack stores no audio format metadata; a future ID3 tag phase will provide real values.
- Shuffle/repeat buttons are intentional no-op placeholders per plan specification D-09 — deferred to a future phase.
