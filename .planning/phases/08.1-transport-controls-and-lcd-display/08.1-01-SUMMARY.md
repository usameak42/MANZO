## What Was Built

### ManzoLCDView.swift (237 lines)

Five CATextLayer fields on a P3 pure-black background at 275×43pt:

- `titleLayer` — scrolling song title (x=111, y=11, 154×10 view-local). Shifts left 0.5pt per poll tick via `tickTitleScroll()` when text exceeds 154pt width. Loops with `" *** "` spacer (D-05).
- `timeLayer` — elapsed/remaining time digits (x=36, y=12, 64×13). NSTrackingArea over this rect; mouseDown toggles `isShowingRemaining: Bool`. `updateTime(position:duration:)` formats as "m:ss" or "-m:ss".
- `bitrateLayer` — kbps value or "---" (x=111, y=29)
- `kHzLayer` — sample rate or "--" (x=156, y=29)
- `stereoLayer` — "STEREO" / "MONO" / "" (x=212, y=27)

Public API for AppDelegate poll wiring (D-12): `updateTime(position:duration:)`, `tickTitleScroll()`, `updateTrack(title:bitrate:kHz:stereo:duration:)`, `clearTrack()`.

Constraints respected: `contentsScale=2.0`, `shouldRasterize=false` on all layers, P3 displayP3 throughout, `required init?(coder:) { fatalError }`.

### ManzoSeekBar.swift (120 lines)

Background + fillLayer + thumbLayer at 248×10pt.

- `fillLayer` (P3 green 0.18,0.82,0.18): width = (position / duration) × bounds.width
- `thumbLayer` (P3 bright 0.30,0.95,0.30): 3×10pt, x = fill edge − 1.5
- `isDragging: Bool` — poll timer skips fill update while dragging (prevents jitter)
- `onSeek: ((Double) -> Void)?` — AppDelegate assigns to call `manzo_seek(handle, t)`
- `mouseDown`/`mouseDragged` provide live seek + immediate visual feedback
- `mouseUp` clears isDragging

T-08.1-01 mitigated: x clamped to [0, bounds.width] before seek time computation; ratio stays in [0, 1].
T-08.1-03 mitigated: `guard duration > 0, !isDragging else { return }` in updateFill.

### ManzoSlider.swift (97 lines)

Identical three-layer structure with `minValue`/`maxValue`/`value: Float` properties.

- `value { didSet { updateFill() } }` — fill updates immediately on assignment
- `onValueChanged: ((Float) -> Void)?` — AppDelegate assigns for volume/pan FFI calls
- `mouseDown`/`mouseDragged` both call `updateValue(from:)` — value clamped then dispatched

T-08.1-02 mitigated: x clamped to [0, bounds.width]; normalized ∈ [0,1]; final value = minValue + normalized × (maxValue − minValue) stays in declared range.
