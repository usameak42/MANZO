## Decisions Made

- `ManzoTransportButton` uses full 5-layer `NeoAeroLayerFactory.make` (not `makeSimplified`) — the specular stack reads better at the compact 23×18pt button size than the simplified 2-layer variant
- `label` setter uses `CATransaction.setDisableActions(true)` to suppress implicit animations when poll timer updates the play/pause label; without this the string change would fade/crossfade
- `setupChrome()` called in `init(frame:)` which is correct because AppDelegate sets the frame before init returns, so `bounds.size` equals the passed-in size at call time
- `prev()` does not call `save()` — consistent with the comment on D-11 in PATTERNS.md and CONTEXT.md: index navigation is not a playlist mutation, tracks array is unchanged
